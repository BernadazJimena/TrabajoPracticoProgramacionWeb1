💡 Consejo

Hi es informal y Hello sirve para cualquier situación. Good morning se usa por la mañana, Good afternoon por la tarde y Good evening por la noche. Good night solo se usa para despedirse.

Inglés · Leccion 1: Saludos y presentaciones

1. Aprende a saludar y presentarte

Para saludar, puedes decir Hello. Para presentarte, puedes decir My name is Ana.

Hello / Hi → hola

Good morning → buenos días

My name is Ana → me llamo Ana

Nice to meet you → encantado de conocerte

2. Ejercicio práctico

Selecciona la traducción correcta.

¿Qué significa Hello?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Hello significa «hola».

Todavía no. Hello significa «hola». Puedes elegir otra opción.

3. Ejercicio práctico

Selecciona la traducción correcta.

¿Cómo se dice «buenos días»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Good morning significa «buenos días».

Todavía no. Good night se usa para despedirse de noche y Good evening para saludar de noche. Puedes elegir otra opción.

4. Ejercicio práctico

Selecciona la opción correcta.

¿Cómo se dice «me llamo Ana»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! My name is Ana significa «me llamo Ana».

Todavía no. Se dice My name is: con my name se usa is. Puedes elegir otra opción.

5. Completa la frase

Elige la palabra que falta.

Comprobar respuesta

¡Correcto! Nice to meet you significa «encantado de conocerte».

Todavía no. meet significa «conocer». Puedes elegir otra opción.

6. Ejercicio práctico

Comprobar respuesta

¡Correcto! I'm fine, thank you significa «estoy bien, gracias».

Todavía no. Para decir que estás bien, responde I'm fine, thank you. Puedes elegir otra opción.
