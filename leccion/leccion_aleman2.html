💡 Consejo

Tschüss es informal. Auf Wiedersehen se utiliza en situaciones más formales.

Alemán · Lección 2: Despedidas y cortesía

1. Aprende expresiones básicas

Estas expresiones te permitirán despedirte y ser amable en conversaciones sencillas.

Tschüss! → ¡Chau!

Auf Wiedersehen! → ¡Hasta luego!

Danke! → ¡Gracias!

Bitte! → ¡Por favor! / ¡De nada!

2. Elige una despedida informal

Selecciona la expresión que usarías para despedirte de un amigo.

¿Cuál de estas opciones significa «chau»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Tschüss es una despedida informal.

Todavía no. La respuesta correcta es Tschüss.

3. Practica una expresión de cortesía

Selecciona la traducción correcta.

¿Qué significa Danke?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Danke significa «gracias».

Todavía no. Danke significa «gracias».

4. Usa una expresión de cortesía

Selecciona la traducción adecuada.

¿Qué puede significar Bitte?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Bitte puede significar «por favor» o «de nada».

Todavía no. Bitte se usa para decir «por favor» o «de nada».
