💡 Consejo

En este repaso combinas saludos, shì (是), zài (在) y la palabra ma (吗), que al final de una frase la convierte en pregunta. Lee el diálogo con atención antes de responder.

Chino · Lección 7: Diálogo de repaso

1. Lee el diálogo

Li Ming y Ana se conocen. Lee lo que dicen y fíjate en la traducción.

Lǐ Míng
Nǐ hǎo! Wǒ jiào Lǐ Míng. (你好！我叫李明。) → ¡Hola! Me llamo Li Ming.
Ana
Nǐ hǎo! Wǒ shì Ana. Rènshi nǐ hěn gāoxìng. (你好！我是 Ana。认识你很高兴。) → ¡Hola! Soy Ana. Encantada de conocerte.
Lǐ Míng
Nǐ shì xuéshēng ma? (你是学生吗？) → ¿Eres estudiante?
Ana
Shì, wǒ zài xuéxí Zhōngwén. (是，我在学习中文。) → Sí, estoy estudiando chino.

2. Ejercicio práctico

Elige la respuesta adecuada.

Li Ming dice Nǐ hǎo! Wǒ jiào Lǐ Míng. ¿Qué responde Ana?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Ana saluda y se presenta: Nǐ hǎo! Wǒ shì Ana.

Todavía no. Cuando alguien se presenta, saludas y dices tu nombre. Puedes elegir otra opción.

3. Completa la frase

Elige la palabra que falta.

Rènshi nǐ hěn ___ (认识你很___) (Encantada de conocerte.)
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Rènshi nǐ hěn gāoxìng (认识你很高兴) significa «encantada de conocerte».

Todavía no. gāoxìng (高兴) significa «contento». Puedes elegir otra opción.

4. Ejercicio práctico

Selecciona el significado correcto.

¿Qué significa Nǐ shì xuéshēng ma? (你是学生吗？)
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Nǐ shì xuéshēng ma? significa «¿eres estudiante?».

Todavía no. xuéshēng (学生) significa «estudiante». Puedes elegir otra opción.

5. Completa la frase

Elige la palabra que falta.

Wǒ ___ xuéxí Zhōngwén (我___学习中文) (Estoy estudiando chino.)
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Wǒ zài xuéxí Zhōngwén (我在学习中文) significa «estoy estudiando chino».

Todavía no. Para una acción en curso se usa zài (在). Puedes elegir otra opción.

6. Ejercicio práctico

Selecciona la opción correcta.

¿Qué palabra se pone al final para hacer una pregunta?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! ma (吗) al final convierte la frase en pregunta.

Todavía no. La palabra de pregunta es ma (吗). Puedes elegir otra opción.

7. Ejercicio práctico

Selecciona la opción correcta.

¿Cómo se dice «ella es mi hermana mayor»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Tā shì wǒ jiějie (她是我姐姐) significa «ella es mi hermana mayor».

Todavía no. Para decir «es» se usa shì (是). Puedes elegir otra opción.
