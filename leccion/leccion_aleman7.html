Alemán · Lección 7: Diálogo de repaso

1. Lee un diálogo completo

Este diálogo combina las expresiones principales del curso.

Ana
Hallo! Ich heiße Ana. Wie heißt du?
Leo
Hallo! Mein Name ist Leo.
Ana
Wie geht es dir?
Leo
Mir geht es gut, danke.
Ana
Tschüss!

2. Completa el diálogo

Selecciona la respuesta más adecuada.

Hallo! Wie heißt du?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Ich heiße Marta responde la pregunta por el nombre.

Todavía no. La pregunta pide el nombre, por eso corresponde Ich heiße Marta.

3. Cierra la conversación

Elige una despedida apropiada.

¿Qué expresión usarías para finalizar el diálogo?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Tschüss permite finalizar una conversación informal.

Todavía no. La despedida adecuada es Tschüss.
