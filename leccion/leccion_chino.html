💡 Consejo

Nǐ hǎo (你好) significa «hola». Para saludar con más respeto se usa Nín hǎo (您好). Para presentarte, di Wǒ jiào… (我叫…), que significa «me llamo…».

Chino · Lección 1: Saludos y presentaciones

1. Aprende a saludar y presentarte

Para saludar, puedes decir Nǐ hǎo (你好). Para presentarte, puedes decir Wǒ jiào Ana (我叫 Ana).

Nǐ hǎo (你好) → hola

Zàijiàn (再见) → adiós

Xièxie (谢谢) → gracias

Wǒ jiào Ana (我叫 Ana) → me llamo Ana

Rènshi nǐ hěn gāoxìng (认识你很高兴) → encantado de conocerte
