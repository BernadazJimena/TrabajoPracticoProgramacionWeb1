💡 Consejo

En pasado simple, los verbos regulares terminan en -ed: work → worked. Algunos son irregulares: go → went. El pasado continuo se forma con was / were + verbo con -ing: I was reading.

Inglés · Lección 4: Pasado simple y continuo

1. Aprende los pasados

Para una acción terminada usa el pasado simple: I worked. Para una acción que estaba en curso usa el pasado continuo: I was working.

I worked → yo trabajé

She went → ella fue

I was reading → yo estaba leyendo

They were playing → ellos estaban jugando

2. Ejercicio práctico

Selecciona la opción correcta.

¿Cómo se dice «yo trabajé ayer»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! I worked yesterday significa «yo trabajé ayer».

Todavía no. Para el pasado de un verbo regular se agrega -ed: worked. Puedes elegir otra opción.

3. Completa la frase

Elige la palabra que falta.

She ___ to the park yesterday. (Ella fue al parque ayer.)
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! went es el pasado de go.

Todavía no. go es irregular: su pasado es went. Puedes elegir otra opción.

4. Ejercicio práctico

Selecciona la traducción correcta.

¿Cómo se dice «yo estaba leyendo»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! I was reading significa «yo estaba leyendo».

Todavía no. Con I se usa was + verbo con -ing. Puedes elegir otra opción.
