💡 Consejo

Con los números del 1 al 10 puedes formar los demás: 11 es shí yī (十一), «diez y uno», y 20 es èr shí (二十), «dos dieces». Para la hora se usa diǎn (点): sān diǎn (三点), «las tres».

Chino · Lección 5: Números y la hora

1. Aprende los números y la hora

Los primeros números son yī, èr, sān (一, 二, 三). Para preguntar la hora se dice Xiànzài jǐ diǎn? (现在几点？).

  • yī (一) uno
  • èr (二) dos
  • sān (三) tres
  • sì (四) cuatro
  • wǔ (五) cinco
  • liù (六) seis
  • qī (七) siete
  • bā (八) ocho
  • jiǔ (九) nueve
  • shí (十) diez

èr shí (二十) → veinte

Xiànzài jǐ diǎn? (现在几点？) → ¿Qué hora es?

Sān diǎn (三点) → son las tres

Todavía no. sì (四) es «cuatro» y qī (七) es «siete». Puedes elegir otra opción.

4. Ejercicio práctico

¡Correcto! Xiànzài jǐ diǎn? (现在几点？) significa «¿qué hora es?».

Todavía no. Nǐ jiào shénme míngzi? pregunta el nombre y Nǐ hǎo ma? pregunta cómo estás. Puedes elegir otra opción.

Todavía no. Para la hora se usa diǎn (点). Puedes elegir otra opción.

6. Ejercicio práctico

Todavía no. èr shí (二十) es «dos dieces»: veinte. Puedes elegir otra opción.

7. Ejercicio práctico

Selecciona la opción correcta.

¿Cómo se dice «son las tres»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Sān diǎn (三点) significa «son las tres».

Todavía no. sān shí (三十) es «treinta»; para la hora se usa diǎn (点). Puedes elegir otra opción.
