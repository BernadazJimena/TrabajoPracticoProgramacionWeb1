💡 Consejo

Ich heiße se usa para decir «me llamo». La letra ß tiene un sonido parecido a una doble s.

Alemán · Lección 3: Decir tu nombre

1. Aprende a presentarte

Estas frases sirven para decir tu nombre y preguntarle el suyo a otra persona.

  • Ich heiße Ana.Me llamo Ana.
  • Mein Name ist Leo.Mi nombre es Leo.
  • Wie heißt du?¿Cómo te llamas?

2. Reconoce una presentación

Selecciona la traducción correcta.

¿Qué significa Ich heiße Sofia?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Ich heiße Sofia significa «Me llamo Sofía».

Todavía no. Ich heiße significa «me llamo».

3. Pregunta el nombre

Elige la pregunta adecuada.

¿Cómo preguntarías «¿Cómo te llamas?»?
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Wie heißt du? pregunta el nombre.

Todavía no. Para preguntar el nombre se usa Wie heißt du?.

4. Completa la presentación

Elige la palabra que falta.

Mein ___ ist Leo.
Comprobar respuesta

Selecciona una opción para comprobarla.

¡Correcto! Mein Name ist Leo significa «Mi nombre es Leo».

Todavía no. La palabra que falta es Name.
